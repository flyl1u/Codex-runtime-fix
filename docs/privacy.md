# 采集与分享范围

诊断采集器仅输出以下白名单字段。它不调用网络 API、不上传数据、不保存文件、不执行修复操作。查询 Windows 事件或可选的日志标记需要本地读取权限。观察器与组件修复助手的行为在下文单独说明。

| 数据 | 输出方式 |
| --- | --- |
| Windows | 版本号、构建号、体系结构 |
| Codex / Primary Runtime | 包名、版本、状态 |
| 相关进程 | 数量、主进程名称、运行秒数、响应状态、内存占用和句柄数量 |
| 资源 | 总内存和空闲内存、系统/profile 所在本地卷的容量与剩余空间；不输出卷标或用户名路径 |
| Crashpad | 按已知目录范围统计近期文件数量及最近写入时间；不读取转储或 sidecar 正文 |
| AppX 部署事件 | 时间、事件编号、级别、匹配到的十六进制错误码；不输出原始事件消息 |
| 应用错误事件 | 与 Codex 相关的时间、事件编号、应用/模块文件名和异常码；不输出完整路径或消息 |
| Microsoft WindowsAppRuntime 部署扩展 | 登记名称、DLL 存在状态或读取异常类型；不输出 DLL 完整路径 |
| 可选日志核对 | 当前进程相关日志的扫描数量、预定义依赖/渲染/工具错误标记名称；不输出日志原文 |
| 采集异常 | 固定检查名称与异常类型；不输出异常消息、堆栈或本机路径 |

进程命令行和日志原文可能被本地代码临时读取，以确定主进程或匹配标记，它们不会写入结果。采集器不读取认证文件、聊天数据库、浏览器存储、项目文件或任何崩溃内存。

部署事件最多读取指定时间范围内最近的 200 条，再筛选与 Codex 相关的事件。可选日志检查每个目录范围最多读取 8 个当前进程日志，跳过大于 10 MB 的文件。空结果不等于历史上没有故障。

应用事件最多读取最近 100 条候选事件，再筛选与 Codex 相关的记录。新资源字段用于提出进一步检查问题，不能根据单个样本断定根因。稳定性观察器会写入明确指定的本地结果文件；Windows 组件修复器在实时修复模式下会修改系统组件，默认保留其无重启行为，项目开发仅使用预演。

分享前仍应查看输出，确认其中没有你不希望公开的时间和软件版本。Issue 只需要症状、版本、错误码和摘要。

公开仓库排除原始日志、`.dmp`、`.reg`、数据库、认证文件、安装包和 DLL。`.gitignore` 只是防止误添加的辅助措施，发布者必须检查实际提交和压缩包内容。
